IOIS FINAL DEPLOY CHECKLIST

1. Upload all files inside this folder to the repository root.
2. Keep index.html at the root.
3. In Supabase SQL Editor run:
   supabase/sql/iois-community-chat.sql
4. In Supabase Storage make sure bucket "member-documents" exists and has the required RLS policies for the existing registration flow.
5. Deploy the Telegram Edge Function from:
   supabase/functions/iois-registration-notification/index.ts
6. Set TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID as Supabase Edge Function secrets.
7. Configure Supabase Auth Site URL and Redirect URLs for the final deployed website.
8. Do not upload any service_role key or Telegram bot token to GitHub.
